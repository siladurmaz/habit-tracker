# 🔥 My Habits — Habit Tracker App

A simple, single-file habit tracker web app. Built from scratch as a project-based way to learn HTML, CSS, and JavaScript.

## ✨ Features

- ✅ Click habits to mark them as done
- 💾 Data persists in the browser (`localStorage`) — survives page reloads and closing the tab
- 🔥 Daily streak tracking — counts consecutive days where every habit was completed
- 📊 Daily progress bar
- 🎨 Smooth transition animations and a clean, modern look

## 🛠️ Tech stack

- **HTML** — page structure
- **CSS** — styling and animations
- **JavaScript** — click logic, data storage, streak calculation

No frameworks or libraries — just vanilla HTML/CSS/JS. The goal was to understand the fundamentals from the ground up.

## 🚀 How to use

Clone or download the repo, open `index.html` in any browser. No installation or server needed.

```bash
git clone https://github.com/siladurmaz/aliskanlik.git
cd aliskanlik
open index.html
```

## 📚 Learning notes

This project was built to hands-on learn:

- HTML document structure (`head` / `body` separation)
- CSS styling and `transition` effects
- DOM manipulation (`querySelectorAll`, `classList`, `getElementById`)
- Event handling (`onclick`)
- Browser storage (`localStorage`) and JSON conversion (`JSON.stringify` / `JSON.parse`)
- Date handling (`Date` object) for streak-calculation logic
